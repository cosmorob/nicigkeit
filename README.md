## Demo im virtuellen Gerät in Android Studio

Voraussetzungen:
- Android Studio installiert (https://developer.android.com/studio)
- Android SDK Command-line tools installiert (Siehe Android Studio > Einstellungen > Languages & Frameworks > Android > SDK Tools)
- Dart SDK installiert (https://dart.dev/get-dart)
- Flutter SDK installiert (https://docs.flutter.dev/install)

Installation mit virtuellem Gerät:
1. In Android Studio im "Device Manager" ein virtuelles Gerät (Phone) hinzufügen, z. B. "Medium Phone" (API 21+, Android 5.0 oder neuer)
2. Abhängigkeiten installieren, siehe ``pubspec.yml``: ``flutter pub get``
3. Virtuelles Gerät "Medium Phone" in Android Studio in der Leiste oben wählen und Anwendung starten (grüner Play-Button) oder ``flutter run -d emulator-5554`` ausführen.
4. Die Anwendung wird im Fenster "Running Devices" angezeigt.

Source Code unter ``lib/main.dart``.
